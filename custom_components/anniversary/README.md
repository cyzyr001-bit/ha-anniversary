# 纪念日（Anniversary）

Home Assistant 自定义集成：为生日、结婚纪念日、发薪日、固定倒计时等创建一个或多个「纪念日」传感器。

## 功能

- 每个配置条目创建一个传感器，可创建多个纪念日
- 阳历 / 农历互转（1900-2100）
- 周期：无（固定日期）、年（生日/周年）、月（发薪日等）
- 显示方式：绝对值（始终正数）/ 带符号（过期后显示负数）
- 显示样式只有 3 种：
  - 年月日（文本，例如 `1年2月3日`）
  - 年月日时分秒（文本，例如 `3日0时2分12秒`）
  - 日（数字，剩余天数）
- 文本样式会自动省略最前面的 0：
  - `0年0月3日0时2分12秒` → `3日0时2分12秒`
  - `0年0月0日0时2分12秒` → `2分12秒`
- 选择日期时，年份可以直接输入（例如直接输入 2050），月份和日期用下拉框
- 可配置更新间隔，默认 3600 秒

## 安装

### 手动安装

把 `custom_components/anniversary` 整个目录复制到 Home Assistant 配置目录：

```text
/config/custom_components/anniversary/
```

然后重启 Home Assistant，在「设置 → 设备与服务 → 添加集成」中搜索「纪念日」。

## 配置项

| 配置项 | 说明 |
| --- | --- |
| 名称 | 传感器名称，例如「结婚纪念日」 |
| 年 | 直接输入年份，例如 2050；范围 1900-2100 |
| 月 | 选择 1-12 月 |
| 日 | 选择 1-31 日；农历小月没有三十时自动取月末 |
| 农历/阳历 | 日期按哪种历法计算 |
| 显示方式 | 绝对值始终正数；带符号过期后显示负数 |
| 显示样式 | 年月日 / 年月日时分秒 / 日 |
| 周期 | 无 / 年 / 月 |
| 闰月 | 仅农历有效；表示所选月份是闰月 |
| 更新时间 | 重新计算间隔，单位秒，默认 3600 |

### 农历日期怎么填

农历模式下，年/月/日三个字段都按农历解释，而不是公历日期。

例如：妈妈生日是农历八月十五，可以填「年 1990、月 8、日 15」并选择「农历」。集成会把它当作农历 1990 年八月十五。

如果生日在闰月，勾选「闰月」。遇到该年没有这个闰月时，会自动按普通月处理；遇到小月没有三十时，会自动取该月最后一天。

## 周期说明

- **无**：只倒计时到填写的固定日期，适合一次性倒计时。
- **年**：每年重复。适合生日、结婚纪念日。目标日期会取「今天或之后最近的一次」。
- **月**：每月重复。适合发薪日、每月还款日。目标日期会取「今天或之后最近的一次」；如果当月没有该日（例如 31 号），自动取当月最后一天。

## 显示规则

| 样式 | 类型 | 示例 |
| --- | --- | --- |
| 年月日 | 文本 | `1年2月3日` |
| 年月日时分秒 | 文本 | `3日0时2分12秒` |
| 日 | 数字 | `3`（天） |

- 「年月日」和「日」按自然日计算，目标当天为 `0`。
- 「年月日时分秒」按精确时长计算，包含时/分/秒。
- 选择「绝对值」时，过期后仍显示正数。
- 选择「带符号」时，过期后文本前面会带 `-`，数字为负数。
- 文本样式只省略最前面的 0；第一个非零分量之后的 0 会保留，例如 `3日0时2分0秒`。

## 属性

每个传感器会附带以下属性：

- `target_date`：计算出的目标日期（ISO 格式）
- `signed_seconds`：带符号的剩余秒数
- `days`：带符号的剩余自然日
- `period`：`none` / `year` / `month`
- `calendar`：`solar` / `lunar`
- `display_mode`：`absolute` / `signed`
- `style`：显示样式
- `is_past`：目标日期是否已过

## 说明

- 农历数据覆盖 1900-2100 年，数据表参考香港天文台公布的公历/农历对照表。
- 本集成不依赖第三方 Python 包，农历转换代码随集成一起提供。
- 修改配置后集成会自动重载传感器。
